Introduction to C

C is a powerful programming language developed by Dennis Ritchie. It is widely used for system programming and application development. C is known for its speed, efficiency, and flexibility.

Features of C

  • Simple and efficient
  • Structured programming language
  • Portable
  • Supports low level programming

Basic Structure of C Program

Part Description
Header Files Used to include libraries like stdio.h
Main Function Execution of program starts from main()
Statements Instructions written inside main()

Example Program

#include <stdio.h>

void main()
{
    printf("Hello World");
}
